\## 考察知识点

1\. \*\*自顶向下的程序设计方法\*\*：把复杂问题拆分成函数，分层实现；

2\. \*\*自底向上测试思想\*\*：逐个函数测试，再组合成完整程序；

3\. \*\*Python计算生态\*\*：理解第三方库的定位、查找项目主页、pip安装；

4\. \*\*随机模拟蒙特卡洛思想\*\*：体育比赛概率模拟，大量重复试验统计竞技规律；

5\. \*\*Pillow图像处理\*\*：像素遍历、卷积运算、图像滤波；

6\. \*\*子进程调用\*\*：Python调用外部命令行工具（you-get）；

7\. \*\*图论可视化\*\*：NetworkX构建图结构、布局绘图；

8\. \*\*Panda3D基础场景\*\*：3D基础模型、相机、渲染窗口。

解题思路 \& 本章学习心得

&#x20;   本章和前面章节单纯学习语法不一样，重点学习工程化的程序设计思维。

&#x20;   自顶向下设计教会我拿到一个复杂问题时，不要一上来就写细节代码，而是先拆解问题、划分功能函数，定义好各个模块的输入输出接口；自底向上测试则要求我们逐个验证每个小函数是否正确，再拼接成完整程序，方便定位 bug。

&#x20;   同时我理解了 Python 计算生态的意义：Python 强大不在于内置语法，而在于丰富的第三方库。遇到图像、网络图、3D 渲染这类需求，优先查找成熟库复用能力，而不是从零手写全部逻辑。

&#x20;   8.1 和 8.2 的体育竞技模拟，利用蒙特卡洛思想，通过随机数模拟单回合胜负，大量重复仿真来统计竞技规律。对比乒乓球和篮球两种规则，能直观看到竞赛规则对胜负结果分布的影响。

&#x20;   Pillow 图像编程让我接触到图像本质是像素矩阵，浮雕效果依靠相邻像素差值运算实现，模糊可以使用内置滤波。

&#x20;   NetworkX 则提供了简单的图结构建模能力，可以快速构建节点与边并可视化。

&#x20;   学习中也遇到不少难点：不同第三方库安装难度差异很大，部分库受系统、Python 版本限制容易安装失败；you-get 作为命令行工具，不能直接 import 导入，需要通过 subprocess 调用；图像处理时很容易因为图片路径错误导致程序找不到文件。

&#x20;   总的来说，本章让我建立起 “先设计、后编码、分模块测试、善用计算生态” 的编程习惯。
